# Audit Backend

Act as a senior backend architect and audit the TrackNariño backend.

Analyze:
- Express server setup
- Route structure
- Controllers
- Services
- Models and MongoDB schemas
- Authentication and authorization
- Request validation
- Error handling
- Logging
- API response consistency
- MongoDB query performance
- GPS, alert, opportunity, and user flows

Find:
- Broken endpoints
- Missing validations
- Security risks
- Duplicated queries or logic
- Incorrect status codes
- Missing pagination
- Weak persistence for critical alerts
- Backend/frontend contract mismatches

Return:
1. Critical backend issues
2. Medium backend issues
3. Low priority cleanup
4. Recommended controller/service/repository structure
5. Specific endpoint fixes
6. Database/index recommendations
