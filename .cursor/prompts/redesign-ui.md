# Redesign UI

Redesign the Flutter app to look like a premium logistics startup application.

Goals:
- Completely modernize UI
- Improve UX
- Create professional navigation
- Add smooth animations
- Improve maps experience
- Improve dashboard quality
- Improve typography
- Improve spacing system
- Improve loading states
- Add skeleton loaders
- Add polished cards
- Add dark mode support

Design references:
- Uber Freight
- Linear
- Stripe
- Tesla UI
- Cabify Driver

The app must stop looking like a student project and feel like a real funded startup product.
