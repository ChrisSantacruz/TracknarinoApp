# Fix Endpoints

Review and fix TrackNariño backend endpoints professionally.

Goals:
- Fix broken responses
- Validate all request bodies and params
- Protect sensitive endpoints
- Use correct HTTP status codes
- Return predictable JSON
- Keep compatibility with the Flutter app
- Remove duplicated controller logic
- Move business logic into services
- Add centralized error handling where needed
- Add pagination to growing list endpoints
- Validate GPS/location data
- Persist security alerts reliably

Before editing:
1. Identify endpoint contracts used by Flutter
2. Detect backend/frontend mismatches
3. Explain root causes
4. Plan minimal safe changes

After editing:
- Verify related routes
- Check affected frontend service calls
- Report remaining risks or missing tests
