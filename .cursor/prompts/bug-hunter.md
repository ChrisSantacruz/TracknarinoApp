# Bug Hunter

Act as a senior QA engineer and bug hunter.

Analyze:
- Screen transitions
- Navigation
- State persistence
- API synchronization
- Form validation
- GPS tracking
- Notifications
- Realtime updates
- Offline sync

Find:
- Hidden bugs
- Race conditions
- UI inconsistencies
- State bugs
- Backend/frontend mismatches
- Broken persistence
- Memory leaks
- Async failures

Then fix them systematically.

Before fixing:
1. Explain the root cause
2. Explain user impact
3. Identify related frontend and backend files
4. Propose the safest permanent fix

After fixing:
- Verify related screens
- Verify related endpoints
- Report remaining risks and recommended tests
